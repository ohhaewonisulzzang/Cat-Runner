게임에 "더위 서바이벌 시스템"을 추가해주세요:

**1. 더위 상태 바 UI 생성**
- **위치**: 화면 우측 상단, 점수 표시 바로 아래에 배치
- **크기**: 너비 150-200px, 높이 20-25px 정도의 가로 바 형태
- **디자인**:
  - 배경: 어두운 회색 또는 검은색 테두리
  - 게이지 색상: 주황색 → 빨간색 그라데이션 (더위 느낌)
  - 게이지가 50% 이하일 때 깜빡이는 효과 추가
  - 바 위에 "💧 수분" 또는 "HEAT" 텍스트 표시

**2. 게이지 감소 메커니즘**
- **초기값**: 100% (최대 게이지)
- **감소 속도**: 초당 2-3% 정도로 지속적으로 감소
- **시각적 피드백**:
  - 게이지가 30% 이하일 때 빨간색으로 변경
  - 10% 이하일 때 빠르게 깜빡임
  - 화면에 열기 효과(파동 효과) 추가 가능

**3. 물 아이템 시스템**
- **아이템 외형**:
  - 파란색 물병 아이콘 ( svg 활용 )
  - 크기: 다른 장애물의 70% 정도
  - 반짝이는 애니메이션 효과
  
- **생성 규칙**:
  - 5-8초마다 랜덤한 높이에 생성
  - 화면에 동시에 존재하는 물 아이템은 최대 2개
  - 일반 장애물과 겹치지 않도록 배치
  
- **회복 효과**:
  - 물 아이템 획득 시 게이지 +25% 회복
  - 획득 시 효과음과 파란색 파티클 효과
  - 획득 시 "+25%" 텍스트 애니메이션 표시

**4. 게임오버 조건**
- 더위 게이지가 0%에 도달하면 즉시 게임오버
- 게임오버 메시지: "탈수! 물을 충분히 마시지 못했습니다"
- 일반 충돌 게임오버와 구분되는 메시지 표시

**5. 종료조건 **
- 빙하 맵으로 바뀌는 순간 해당 기능은 전부 동작하지 않음
