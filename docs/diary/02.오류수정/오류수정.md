다음 게임 코드를 수정해주세요:

**필수 수정 사항:**

1. **UI 수정**
   - 게임 오버 시 나타나는 "다시하기" 버튼을 완전히 제거해주세요
   - 게임 재시작은 스페이스바나 클릭만으로 가능하도록 해주세요

2. **장애물 생성 버그 수정**
   - 현재 장애물이 게임 초반에만 생성되고 시간이 지나면 더 이상 생성되지 않는 버그가 있습니다
   - 게임이 진행되는 동안 장애물이 지속적으로 생성되도록 수정해주세요
   - 장애물 생성 로직의 타이머나 조건문을 확인하고 수정해주세요

3. **난이도 조정 (어렵게)**
   - **장애물 간격**: 현재보다 30-40% 좁게 설정해주세요
   - **생성 빈도**: 장애물 생성 간격을 현재의 절반 수준으로 줄여서 더 자주 나오도록 해주세요
   - 예시: 현재 2초마다 생성된다면 → 1초마다 생성
   - 게임 진행 시간에 따라 점진적으로 더 어려워지도록 난이도 증가 로직도 추가해주세요

**검증 사항:**
- 최소 1분 이상 게임을 플레이했을 때도 장애물이 계속 생성되는지 확인
- 게임 오버 후 재시작이 버튼 없이 정상 작동하는지 확인
