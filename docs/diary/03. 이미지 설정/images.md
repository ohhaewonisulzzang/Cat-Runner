# 게임 이미지 요구사항 문서

## 개요
Cat Runner 게임에 필요한 이미지 파일들의 상세 스펙 문서입니다.

---

## 1. 플레이어 캐릭터 (고양이)

### 기본 스펙
- **파일명**: cat_idle.png, cat_run_1.png, cat_run_2.png, cat_run_3.png, cat_run_4.png, cat_jump.png
- **크기**: 50x50 픽셀
- **포맷**: PNG (투명 배경)
- **용도**: 플레이어 캐릭터 애니메이션

### 상태별 이미지

#### 1.1 대기 상태 (cat_idle.png)
- 고양이가 정지해 있는 기본 포즈
- 귀여운 고양이 디자인
- 눈, 귀, 꼬리가 명확히 보여야 함

#### 1.2 달리기 애니메이션 (cat_run_1~4.png)
- 4프레임 달리기 애니메이션
- 각 프레임은 다리 동작이 자연스럽게 연결되어야 함
- 프레임 순서: run_1 → run_2 → run_3 → run_4 → 반복
- 애니메이션 속도: 0.1초/프레임

#### 1.3 점프 상태 (cat_jump.png)
- 공중에 떠 있는 포즈
- 다리를 약간 웅크린 자세
- 꼬리를 뻗은 모습

### 색상 참고
- 현재 임시 색상: #FF6B6B (연한 빨강)
- 점프 중: #FFB74D (주황)
- 점프 차징: #FF9800 → #FFC107 → #4CAF50 (단계별)

## 2. 장애물

### 2.1 지면 장애물

#### 작은 장애물 (obstacle_ground_small.png)
- **크기**: 30x30 픽셀
- **색상**: #8B4513 (갈색)
- **디자인**: 바위, 나무 그루터기, 작은 돌 등
- **용도**: 짧은 점프로 넘을 수 있는 장애물

#### 중간 장애물 (obstacle_ground_medium.png)
- **크기**: 50x50 픽셀
- **색상**: #A0522D (새들브라운)
- **디자인**: 큰 바위, 나무 상자 등
- **용도**: 중간 점프 필요

#### 큰 장애물 (obstacle_ground_large.png)
- **크기**: 70x70 픽셀
- **색상**: #654321 (다크브라운)
- **디자인**: 거대한 바위, 큰 장애물
- **용도**: 높은 점프 필요

### 2.2 공중 장애물

#### 작은 공중 장애물 (obstacle_air_small.png)
- **크기**: 30x30 픽셀 (원형)
- **색상**: #FF6B6B (빨강)
- **디자인**: 새, 박쥐, 날아다니는 곤충
- **높이**: 480px (점프로 닿을 수 있는 높이)
- **특징**: 날개 애니메이션 효과 포함 권장

#### 중간 공중 장애물 (obstacle_air_medium.png)
- **크기**: 50x50 픽셀 (원형)
- **색상**: #FF5722 (주황빨강)
- **디자인**: 큰 새, 독수리 등
- **높이**: 420px (중간 점프 높이)

#### 큰 공중 장애물 (obstacle_air_large.png)
- **크기**: 70x70 픽셀 (원형)
- **색상**: #D32F2F (진빨강)
- **디자인**: 거대한 새, 드론 등
- **높이**: 380px (높은 점프 필요)

## 4. 배경 요소

#### 구름 (cloud.png)

- **색상**: rgba(255, 255, 255, 0.8)
- **디자인**: 뭉게구름 형태
- **개수**: 다양한 크기 3-5종류
- **용도**: 배경 스크롤 (0.3배속)

- **줄기**: #8B4513 (갈색), 10x50px
- **잎**: #228B22 (초록), 삼각형 모양
- **용도**: 배경 데코레이션 (0.5배속 스크롤)

#### 풀 패턴 (grass.png)
- **크기**: 20x10 픽셀
- **색상**: #32CD32 (라임 그린)
- **디자인**: 작은 풀 뭉치
- **용도**: 지면 패턴 (게임 속도와 동일)

## 7. 애니메이션 스펙

### 7.1 플레이어
- **달리기**: 4프레임, 0.1초/프레임
- **점프**: 단일 프레임 (정지)
- **착지**: 달리기 애니메이션 재개

### 7.2 장애물
- **공중 장애물**: 날개 펄럭임 (0.05초 간격)
- **물 아이템**: 반짝이는 효과 (sin 파동)

### 7.3 배경
- **구름**: 0.3배속 스크롤
- **나무/화산/빙산**: 0.4-0.5배속 스크롤
- **지면**: 게임 속도와 동일

## 9. 현재 구현 상태

- ✅ 플레이어 캐릭터 (사각형 + 눈)
- ✅ 지면 장애물 (사각형 + 그림자)
- ✅ 공중 장애물 (원형 + 날개)
- ✅ 물 아이템 (물병 모양)

### 이미지 적용 필요
- ❌ 모든 요소에 실제 이미지 적용 예정

## 10. 추가 고려사항

### 10.1 반응형 디자인
- 캔버스 크기: 1280x720 (16:9)
- 고해상도 디스플레이 지원 (devicePixelRatio)
- 모든 이미지는 2배 해상도 버전 제공 권장 (@2x)

### 10.2 최적화
- 스프라이트 시트 사용 고려
- PNG 압축 최적화
- 파일 크기 최소화

### 10.3 스타일 가이드
- 일관된 아트 스타일 유지
- 귀여운/캐주얼 게임 느낌
- 선명한 색상 대비
- 픽셀 아트 또는 벡터 스타일 권장
