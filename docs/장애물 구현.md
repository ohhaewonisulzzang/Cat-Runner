# 장애물 시스템 구현

## 개요

Cat-Runner 게임의 장애물 시스템은 땅 장애물, 공중 장애물, 그리고 용암 맵의 물 아이템으로 구성됩니다.

## 시스템 구성

### 1. ObstacleImageLoader 클래스

장애물 이미지를 로드하고 관리하는 클래스입니다.

**주요 속성:**
- `images`: 이미지 객체 저장
  - `ground`: 땅 장애물 (small, medium, large)
  - `air`: 공중 장애물 (small, medium, large)
- `loaded`: 이미지 로딩 완료 여부
- `loading`: 이미지 로딩 진행 중

**이미지 구조:**
```
src/assets/images/obstacles/glassland/
├── ground/
│   ├── small/ (small_01.png ~ small_04.png)
│   ├── medium/ (medium_01.png ~ medium_04.png)
│   └── large/ (large_01.png ~ large_06.png)
└── air/
    ├── small/ (small_01.png ~ small_04.png)
    ├── medium/ (medium_01.png ~ medium_04.png)
    └── large/ (large_01.png ~ large_06.png)
```

**주요 메서드:**
- `loadImages()`: 모든 장애물 이미지를 로드하고 반환
- `loadImage(img)`: 개별 이미지를 Promise로 로드
- `getRandomImage(type, size)`: 랜덤 이미지 선택

### 2. Obstacle 클래스

개별 장애물 객체를 관리하는 클래스입니다.

**속성 및 매개변수:**
- `x`: X 좌표
- `y`: Y 좌표
- `type`: 'ground' 또는 'air'
- `size`: 'small', 'medium', 'large'

**크기 속성:**

| 크기 | 너비 | 높이 |
|------|------|------|
| small | 45px | 45px |
| medium | 50px | 50px |
| large | 70px | 70px |

**위치 계산:**

**땅 장애물 (ground):**
- Y 좌표: `695 - height`
- 플레이어 기준선(Y=695)에 맞춤

**공중 장애물 (air):**
- small: Y = 530 (점프로 넘을 수 있는 높이)
- medium: Y = 470 (중간 점프 높이)
- large: Y = 430 (높은 점프 필요)

**주요 메서드:**
- `setSizeProperties()`: 크기에 따른 속성 설정
- `update(gameSpeed, deltaTime)`: 위치 업데이트
- `render(ctx)`: 장애물 렌더링 (이미지 또는 도형 렌더링)
- `renderImage(ctx)`: 이미지 렌더링
- `renderGroundObstacle(ctx)`: 땅 장애물 도형 렌더링
- `renderAirObstacle(ctx)`: 공중 장애물 도형 렌더링 (반투명 빨간색)
- `getBounds()`: 충돌 감지용 경계
- `checkPassed(playerX)`: 플레이어 통과 여부 확인
- `getScoreValue()`: 점수 획득 값 반환 (small: 10, medium: 15, large: 20)

**렌더링:**
- 이미지가 로드되면 이미지 렌더링
- 이미지가 없으면 도형 렌더링으로 대체
  - 땅: 갈색 직사각형 + 그라데이션
  - 공중: 밝은 빨간 색상 + 반투명 빨간색

### 3. WaterItem 클래스

용암 맵에서 체력을 회복하는 물 아이템 클래스입니다.

**속성:**
- `width`: 40px
- `height`: 40px
- `active`: 활성화 상태
- `collected`: 수집 여부

**주요 메서드:**
- `update(gameSpeed, deltaTime)`: 위치 업데이트
- `render(ctx)`: 아이템 렌더링 (수집되면 표시 안 함)
- `getBounds()`: 충돌 감지용 경계
- `collect()`: 수집 처리

**생성 규칙:**
- 용암 맵에서만 생성
- 5-8초마다 랜덤 생성
- 화면 2개분의 거리에 생성
- Y 좌표: 400-600 랜덤

**효과:**
- 수집 시 체력 +25% 회복

### 4. ObstacleManager 클래스

모든 장애물과 물 아이템을 관리하는 클래스입니다.

**속성:**
- `obstacles`: 장애물 배열
- `waterItems`: 물 아이템 배열
- `spawnTimer`: 장애물 생성 타이머
- `spawnInterval`: 장애물 생성 간격 (난이도에 따라 변화)
- `waterSpawnTimer`: 물 아이템 생성 타이머
- `waterSpawnInterval`: 물 아이템 생성 간격 (6000ms 고정)
- `groundRatio`: 땅 장애물 비율 (0.6 = 60%)

**장애물 생성 로직:**

**생성 간격 (난이도별):**
```javascript
spawnInterval = max(400ms, 1200ms - (difficulty * 80ms))
```

**타입 선택:**
- 60% 땅, 40% 공중
- 연속 같은 타입 2개까지만 허용

**크기 선택 (난이도별 확률):**

| 난이도 | Large | Medium | Small |
|--------|-------|--------|-------|
| 1 | 0% | 15% | 85% |
| 2 | 5% | 20% | 75% |
| 3 | 10% | 25% | 65% |
| 4 | 15% | 30% | 55% |
| 5 | 25% | 30% | 45% |
| 6 | 35% | 30% | 35% |
| 7 | 45% | 30% | 25% |
| 8 | 55% | 30% | 15% |
| 9 | 70% | 20% | 10% |
| 10 | 85% | 10% | 5% |

**높은 점수 난이도 가중:**
- 20점마다 Large 확률 6% 증가 (최대 30% 증가)

**주요 메서드:**
- `update(deltaTime)`: 모든 장애물과 물 아이템 업데이트
- `spawnObstacle()`: 장애물 생성
- `spawnWaterItem()`: 물 아이템 생성 (용암 맵 전용)
- `determineType()`: 장애물 타입 선택
- `determineSize()`: 장애물 크기 선택
- `checkCollisions(player)`: 충돌 감지
- `checkWaterCollection(player)`: 물 아이템 수집 감지
- `checkPassedObstacles(playerX)`: 통과한 장애물 확인 후 점수 획득
- `render(ctx)`: 모든 장애물 렌더링
- `reset()`: 장애물 초기화

## 충돌 시스템

**충돌 감지 알고리즘:**
```javascript
isColliding(rect1, rect2) {
    return rect1.x < rect2.x + rect2.width &&
           rect1.x + rect1.width > rect2.x &&
           rect1.y < rect2.y + rect2.height &&
           rect1.y + rect1.height > rect2.y;
}
```

**충돌 대상:**
- 플레이어 경계상자 vs 장애물 경계상자
- 플레이어 경계상자 vs 물 아이템 경계상자

## 점수 시스템

**장애물 통과 점수:**
- small: 10점
- medium: 15점
- large: 20점

**점수 획득 규칙:**
- 장애물을 성공적으로 통과할 때 플레이어 X 좌표를 넘어가면 획득
- 각 장애물당 1회만 점수 획득

## 난이도 시스템

**난이도 범위:** 1 ~ 10

**난이도별 생성 간격:**
- 난이도 1: 1200ms
- 난이도 5: 800ms
- 난이도 10: 400ms

**난이도에 따른 변화 효과:**
1. 장애물 생성 간격 감소 (더 빠른 생성)
2. 큰 장애물 비율 증가
3. 점수 난이도 증가 보너스로 난이도 상승

## 용암 맵 전용 시스템

**물 아이템:**
- 용암 맵에서만 생성
- 체력 +25% 회복 효과
- 5-8초마다 랜덤 생성
- 화면 2개분의 거리에 미리 생성

**체력 감소:**
- 난이도에 따라 감소
- 0%에 도달 시 게임 오버
- 물 아이템으로 회복 가능

## 최적화

**성능 최적화:**
- 거리 밖으로 나간 장애물은 자동 제거
- 비활성화된 장애물은 업데이트 및 렌더링 생략
- 이미지 로딩이 완료 될 때까지 1회만 시도

**메모리 관리:**
- 장애물 객체 재사용 방식 대신 삭제
- 배열 크기 적절 유지

## 디버그 정보

**ObstacleManager.getDebugInfo() 반환값:**
- `obstacleCount`: 총 장애물 개수
- `activeObstacles`: 활성화된 장애물 개수
- `spawnTimer`: 현재 생성 타이머 (ms)
- `spawnInterval`: 생성 간격 (ms)
- `consecutiveType`: 연속 생성 타입 및 개수

## 구현 체크리스트

1. 모든 장애물 이미지 로드 (초록색, 용암색)
2. 다양한 장애물 타입 구현
3. 장애물 난이도 시스템 구현
4. 장애물 충돌 및 제거
5. 모든 장애물 시스템
