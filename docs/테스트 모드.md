## 디버그 모드

### 활성화 방법
- **단축키**: ` (백틱 키, ESC 아래)
- **기본 상태**: OFF

### 기능

#### 1. 플레이어 히트박스 시각화
- **녹색 박스**: 실제 충돌 판정 영역
- **빨간 십자선**: 히트박스 중심점
- **반투명 녹색 채우기**: 히트박스 영역 표시

#### 2. 디버그 정보 패널 (좌측 상단)
```
FPS: 현재 프레임률
State: 게임 상태 (playing/paused/gameOver/menu)
Score: 현재 점수
Speed: 게임 속도
Difficulty: 난이도 레벨
Game Time: 게임 경과 시간

Background:
  Current: 현재 배경 맵
  Transitioning: 배경 전환 중 여부
  Transition α: 전환 투명도
  Loaded G: 초원 맵 로딩 상태 (1, 2, 3)
  Loaded L: 용암 맵 로딩 상태 (1, 2)
  Loaded I: 빙하 맵 로딩 상태 (1, 2, 3)

Player:
  Position: 플레이어 좌표 (x, y)
  Velocity: Y축 속도
  Grounded: 지면 접촉 여부

Obstacles:
  Count: 전체 장애물 수
  Active: 활성 장애물 수
  Timer: 생성 타이머
```

### 히트박스 설정
- **플레이어 크기**: 90x90px
- **히트박스 크기**: 50x60px
- **좌우 여백**: 20px
- **상하 여백**: 15px

## 테스트 모드

### 활성화 방법
- **단축키**: F12
- **기본 상태**: OFF

### 기능

#### 1. 점수 조작
- **단축키**: 숫자 1
- **기능**: 현재 점수에 +100점 추가
- **사용 예시**: 특정 점수 구간 테스트 (맵 전환, 난이도 조절 등)

#### 2. 무적 모드
- **단축키**: 숫자 2
- **기능**: 장애물 충돌 무시
- **상태 표시**: 테스트 모드 라벨에 "Invincible ON/OFF" 표시
- **사용 예시**: 장애물 배치 테스트, 배경 확인

#### 3. 수분 게이지 조작
- **단축키**: 숫자 3
- **기능**: 수분 게이지를 10%로 설정
- **사용 예시**: 더위 시스템 테스트, 물 아이템 효과 확인

### 테스트 모드 UI
- **위치**: 우측 상단
- **배경**: 주황색 (rgba(255, 165, 0, 0.8))
- **표시 정보**:
  ```
  TEST MODE
  1: +100 Score
  2: Invincible ON/OFF
  ```

## 개발자 콘솔 명령어

### 게임 엔진 접근
```javascript
// 전역 게임 엔진 객체
window.gameEngine
```

### 유용한 명령어

#### 1. 디버그 모드 제어
```javascript
// 디버그 모드 활성화
gameEngine.debugMode = true;

// 디버그 모드 비활성화
gameEngine.debugMode = false;
```

#### 2. 테스트 모드 제어
```javascript
// 테스트 모드 활성화
gameEngine.testMode = true;

// 무적 모드 활성화
gameEngine.invincible = true;
```

#### 3. 점수 조작
```javascript
// 점수 추가
gameEngine.gameState.updateScore(1000);

// 최고 점수 확인
gameEngine.gameState.gameData.highScore;
```

#### 4. 게임 속도 제어
```javascript
// 게임 속도 변경 (기본값: 5)
gameEngine.gameState.gameData.gameSpeed = 10;

// 게임 속도 초기화
gameEngine.gameState.gameData.gameSpeed = 5;
```

#### 5. 난이도 제어
```javascript
// 난이도 레벨 확인
gameEngine.gameState.gameData.difficultyLevel;

// 수동 난이도 변경 (1-5)
gameEngine.gameState.gameData.difficultyLevel = 3;
```

#### 6. 맵 전환 테스트
```javascript
// 현재 맵 확인
gameEngine.gameState.gameData.currentMap;

// 맵 강제 전환
gameEngine.gameState.gameData.currentMap = 'lava';  // 'grassland', 'lava', 'ice'
```

#### 7. 플레이어 제어
```javascript
// 플레이어 위치 변경
gameEngine.player.x = 300;
gameEngine.player.y = 500;

// 플레이어 점프 강제 실행
gameEngine.player.startJump();

// 플레이어 리셋
gameEngine.player.reset();
```

#### 8. 게임 상태 제어
```javascript
// 게임 상태 변경
gameEngine.gameState.setState('playing');  // 'menu', 'playing', 'paused', 'gameOver'

// 게임 리셋
gameEngine.resetGame();

// 게임 통계 확인
gameEngine.getGameStats();
```

#### 9. 장애물 제어
```javascript
// 모든 장애물 제거
gameEngine.obstacleManager.reset();

// 장애물 생성 간격 조정 (밀리초)
gameEngine.obstacleManager.spawnInterval = 2000;

// 장애물 디버그 정보
gameEngine.obstacleManager.getDebugInfo();
```

#### 10. 배경 제어
```javascript
// 배경 스크롤 속도
gameEngine.backgroundX = 0;  // 배경 초기화

// 배경 전환 강제 실행
gameEngine.startBackgroundTransition('grassland2');
```

## 테스트 시나리오

### 1. 맵 전환 테스트
```javascript
// 초원 → 용암 전환 테스트
gameEngine.gameState.updateScore(1000);

// 용암 → 빙하 전환 테스트
gameEngine.gameState.updateScore(3000);
```

### 2. 난이도 증가 테스트
```javascript
// 무적 모드 활성화
gameEngine.invincible = true;

// 시간 가속 (게임 시간 증가)
gameEngine.gameState.gameData.gameTime = 180;  // 3분
```

### 3. 충돌 판정 테스트
```javascript
// 디버그 모드로 히트박스 확인
gameEngine.debugMode = true;

// 장애물 생성 간격 조정
gameEngine.obstacleManager.spawnInterval = 1000;  // 1초마다 생성
```

### 4. 더위 시스템 테스트
```javascript
// 수분 게이지를 최소로 설정
gameEngine.gameState.gameData.heatGauge = 5;

// 더위 감소 속도 조정
gameEngine.gameState.gameData.heatDecreaseRate = 0.5;
```

## 주의사항

1. **디버그 모드는 성능에 영향을 줄 수 있습니다**
   - 많은 정보를 화면에 렌더링하므로 FPS가 약간 감소할 수 있습니다.

2. **테스트 모드는 게임 밸런스를 깨뜨립니다**
   - 무적 모드나 점수 조작은 정상적인 게임 플레이 데이터를 왜곡할 수 있습니다.
   - 테스트 후에는 항상 모드를 OFF 하고 정상 플레이를 권장합니다.

3. **콘솔 명령어 사용 시 주의**
   - 잘못된 값 입력은 게임 크래시를 유발할 수 있습니다.
   - 변경 후에는 `gameEngine.resetGame()`으로 초기화를 권장합니다.

4. **프로덕션 빌드에서는 비활성화**
   - 실제 배포 버전에서는 테스트 모드 기능을 제거하거나 비활성화해야 합니다.
